Pantone → TPX

Подбор ближайшего оттенка Pantone TPX / TCX по коду Pantone, HEX, RGB или из палитры
Поддерживаются коды печатной палитры Solid Coated (185 C, PMS 2995 C) и коды TCX/TPX (19-4052).
Выберите цвет пипеткой или введите HEX / RGB вручную — совпадение обновится сразу.
Введите через запятую C, M, Y, K в процентах (0–100), например 0, 90, 82, 4. Пересчёт из CMYK в RGB условный (без цветового профиля печатной машины), поэтому используйте для ориентира.

Похожие варианты TPX
Как это работает. Pantone TPX и TCX — один и тот же каталог Fashion, Home + Interiors (FHI), различаются только физическим носителем образца (бумага TPX / хлопок TCX), поэтому коду и оттенку совпадают. Официальных таблиц перевода печатной палитры PMS Solid Coated в TPX компания Pantone не публикует — цвета формируются по разным технологиям (краска для бумаги vs крашеная ткань), поэтому подбор ниже приближённый: цвет переводится в пространство Lab и для него ищется ближайший образец TPX/TCX по формуле ΔE (CIE76) среди 2310 цветов каталога FHI. Чем меньше ΔE, тем точнее совпадение (ΔE ≤ 2 — практически неотличимо на глаз). Значения CMYK считаются по стандартной формуле RGB↔CMYK без учёта ICC-профиля конкретной печатной машины — реальный результат на бумаге может отличаться. Для ответственных задач сверяйтесь с физическим веером Pantone — экранные и печатные цвета всегда отличаются от бумажного/тканевого оригинала.
